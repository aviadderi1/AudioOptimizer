# AD Audio Optimizer for Mac

AD SOUND & SERVICE · prepares a Mac for recording and mixing: closes background apps, pauses Spotlight / Time Machine / updates, prevents sleep, turns off App Nap and Low Power Mode, shows the audio device, sample rate and buffer, checks disks and measures latency. LIVE OPT opens a round floating gauge that stays on top of every app. Everything is undone by **Restore defaults**.

## Download
Go to **Releases → latest** and download `AD-Audio-Optimizer-mac.zip`.
First launch: right-click the app → **Open** → **Open**.

## Build yourself
On a Mac with Xcode command line tools: `./build.sh`
